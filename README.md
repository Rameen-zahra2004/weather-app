# weather-app
A simple and responsive weather app
This Weather App allows users to search for any city and get real-time weather information, including temperature, humidity, and weather conditions. Built with HTML, CSS, and JavaScript, it features a responsive design for desktop and mobile devices, and fetches data using a weather API.

Technologies Used:
HTML | CSS | JavaScript | API | Responsive Design
